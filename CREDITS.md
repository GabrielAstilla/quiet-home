# Wallpaper Credits

Bundled photo wallpapers in `app/src/main/assets/wallpapers/`, shown in Settings › Appearance › Wallpaper › Browse wallpapers
(Nature and Abstract sections). Each file is a 1920×1080 centre crop of the original, re-encoded as JPEG.

**Licence:** [Unsplash License](https://unsplash.com/license). Every photo page below was checked on **2026-11-05** and shows
"Free to use under the Unsplash License". None are Unsplash+.

What the licence allows and doesn't, as stated on the licence page on that date:
- Free to download and use, for commercial and non-commercial purposes, without permission. Attribution isn't required
  (it is given here anyway).
- Photos can't be sold without significant modification.
- Photos can't be compiled "to replicate a similar or competing service".

Quiet Home bundles 11 photos as backgrounds inside a launcher. It doesn't sell them and isn't an image service, so this is
ordinary use under the licence. If you redistribute the APK, keep this file with it. Any of these images can be removed
by deleting it from `assets/wallpapers` and its entry from `Photos.kt`.
